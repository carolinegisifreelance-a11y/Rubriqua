Le glossaire SEO, GEO et SEA

Tout le glossaire
GEOGEO

Optimisation d’un site pour être cité dans les réponses des moteurs génératifs : ChatGPT, Perplexity, Copilot, Gemini et les Aperçus IA de Google.

Lire la définition SEOE-E-A-T

Critères utilisés par Google pour évaluer la qualité d’un contenu : l’expérience vécue de l’auteur, son expertise, l’autorité du site sur le sujet et la fiabilité de l’ensemble.

Lire la définition SEAROAS

Chiffre d’affaires généré pour chaque euro dépensé en publicité.

Lire la définition GEOAperçus IA

Réponses générées par l’IA de Google, affichées en haut de certaines pages de résultats.

Voir dans le glossaire GEOMode IA

Mode de recherche conversationnel de Google, accessible depuis un onglet dédié.

Voir dans le glossaire SEODonnées structurées

Informations ajoutées dans le code d’une page pour décrire son contenu de façon standardisée : organisation, article, produit, questions fréquentes.

Voir dans le glossaire SEOIntention de recherche

Besoin réel derrière une recherche : s’informer, comparer, acheter ou trouver un site précis.

Lire la définition SEONetlinking

Stratégie qui vise à obtenir des liens entrants de qualité : relations presse, partenariats, annuaires professionnels, contenus que d’autres sites ont envie de citer.

Voir dans le glossaire SEOCore Web Vitals

Trois mesures de Google sur l’expérience de chargement et d’utilisation d’une page.

Voir dans le glossaire SEAPerformance Max

Type de campagne Google Ads qui diffuse des annonces sur tous les espaces de Google à partir d’un même budget : recherche, YouTube, Gmail, Discover, Maps et sites partenaires.

Voir dans le glossaire SEOYMYL

Sujets qui peuvent avoir des conséquences sur la santé, la sécurité, la stabilité financière ou le bien-être des personnes.

Voir dans le glossaire GEORecherche sans clic

Recherche qui se termine sans clic vers un site, parce que la réponse s’affiche directement dans Google : Aperçu IA, extrait optimisé, fiche d’entreprise.
